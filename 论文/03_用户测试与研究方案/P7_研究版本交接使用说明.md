# 研究版本与材料交接工具

此功能为 P7 交接准备，不代表真实六人预试或正式研究已完成。

## 使用

1. 在研究工作台读取目标批次，先保存材料和完整计划。
2. 在“研究版本与材料交接”点击“保存并下载版本交接包”。
3. 包内包含材料 PNG、完整笔触计划、问卷、访谈、评分项目、关键评分项、能力差异及协议参数。分别显示当前运行算法和材料实际使用的算法版本，不把历史材料隐式升级。
4. 页面保留最近十份包的下载入口、状态与整个文件的 SHA-256。文件保存到私有 handoffs/{ID}.json 并纳入备份。
5. 在终端校验：`node scripts/verify-study-handoff.mjs "交接包.json" "后台显示的SHA256"`。不提供外部哈希时，只检查包内各部分的一致性，不能据此证明文件来源。

## 状态与边界

- draft：未发布、未审核，或保存的协议版本与当前运行版本不一致，只能作草稿。
- published-pilot：导出时已发布的预试配置。
- published-formal：导出时已发布的正式配置；导出本身不会执行发布。

协议版本不一致时，protocol 字段是当前运行协议快照，savedProtocolVersion 是已存版本，不能拿该草稿还原历史协议。材料哈希不匹配则拒绝导出。文件下载时也核对整包哈希；改动后的文件不会被静默当作原包。

交接包不含口令、参与者记录或参与者实际作品，不替代完整研究数据备份。导入包覆盖现有研究、修改已入组材料、云端发布均不由此按钮执行。真正的正式冻结仍遵循预试复核和原有发布门槛。
