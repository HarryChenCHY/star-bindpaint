# 200 笔预算算法改造（2026-09-10）

本次遵循最新需求，取代原计划的“轮廓 → 大色块 → 小色块”。保持按笔触序列逐笔引导，直接拟合原图，不生成独立轮廓层。以下均为软件工程验证，不是真人实验结果。

## 如何体验

打开 http://localhost:3001/simplify ，选择盆栽、油画或上传自己的图片，查看原图、旧算法完整结果、旧算法前 200 笔与新算法的效果。可拖动进度查看各笔作用，下载效果图，然后进入原有绘画程序。选图页直接“生成星迹并开始”也使用新版算法。

所有比较图从白色画布绘制，不以原图底图伪造相似度。预览是算法理想合成结果，不是用户手绘作品。原有体验中的辅助/自动绘画与研究中的真实手绘仍分开。

## 本次算法的实质修改

1. 从预算内重新规划整张图片，默认上限 200 笔。白图不强行加笔；找不到改善的笔触时允许少于 200。不是生成几千笔后取前 200。
2. 旧实现的误差缓冲只更新中心线附近像素，且同层生成完后才反馈；新版对完整笔刷覆盖区域即时计算误差，每一笔都以更新后的画布为基础。
3. 根据剩余色差采样候选位置，同时提高边缘附近的关注度。每轮比较不同位置、角度、长度、宽度，使用最小二乘拟合颜色，再局部细调参数。
4. 随预算推进减小候选笔刷尺度，前期建立整体、后期修整。没有单独描边步骤，也不强制把动作分到三个阶段。粗尺度未找到合适笔触时仍继续细尺度搜索。
5. 拟合包含透明度混合与抗锯齿近似。原绘画体验按 0.85 透明度拟合；研究画布按现有的不透明画笔拟合。两个使用场景有独立版本标记。
6. 输出仍是原 StrokeDrawData 的颜色、宽度、点序列，由原有渲染与引导系统使用。当前搜索使用圆头直线笔触，保留笔触感；复杂弯曲形状用多笔近似，不等同于旧曲线算法的所有造型能力。
7. 新研究材料使用 `phase: paint`，A/B 共用规范化的原图；已有三阶段材料与研究记录保持可读取，不会自动替换。正式使用新版需在研究后台重新生成并审核材料，冻结同一序列用于同一批次。
8. 算法与新预览不发送图片到外部模型。原图最长边最多 512、优化分析最长边 128，预览与研究生成在 Worker 中执行。原绘画入口按小批次让出主线程。

## 为什么不保证“200 笔精美且完全一致”

有限数量、固定颜色的圆头笔触无法精确表达任意照片的纹理、文字、人脸与密集细线。128 像素的分析图也会弱化小特征。当前方法改善笔触利用率和整体色彩/形状，并没有语义模型来识别人眼、五官或作品中的关键物体。

像素色差 MAE 只衡量平均 RGB 接近程度；它不能衡量美感、主体识别、笔触自然度或零基础使用者能否完成。当前油画结果仍有明显概括的色块，不能写成已实现照片级复原。正式预试应选择主体清晰、形状不复杂的材料，先人工确认关键特征保留，再实际测试时间与满意度。

## 研究技术依据与实现边界

- Huang 等，ICCV 2019，Learning to Paint With Model-Based Deep Reinforcement Learning：通过神经渲染器及强化学习规划笔触位置和颜色。论文支持“有限笔触序列重建图像”的技术方向，不意味着任意图像在 200 笔都有保证。https://openaccess.thecvf.com/content_ICCV_2019/html/Huang_Learning_to_Paint_With_Model-Based_Deep_Reinforcement_Learning_ICCV_2019_paper.html
- Zou 等，CVPR 2021，Stylized Neural Painting：将笔触参数寻找作为提高输入与渲染图相似度的优化过程，并采用神经渲染。https://openaccess.thecvf.com/content/CVPR2021/html/Zou_Stylized_Neural_Painting_CVPR_2021_paper.html

本次是浏览器 CPU 上的独立贪心参数搜索实现，借鉴比较渲染结果、优化参数的思路；没有训练、下载或复现上述神经网络，不能套用论文里的质量指标。后续若精细人像与纹理是刚性要求，应单独评估可微渲染/神经绘画服务、耗时与模型部署，再决定是否扩展预算，而不是直接承诺 200 笔可以无损表达任意画面。

## 验证入口

- `npm run test:study`：领域与算法测试，包含预算、确定性、路径可画性、透明图片、预算改变重新规划。
- `npm run test:study:materials`：12 张工程图重复生成、预算/几何检查与移动端。
- `npm run test:study:browser`：隔离数据库中的 AB/BA 全流程、断线补传、双人评分、导出与权限检查。
- `node tests/study/paint-budget.mjs`：3001 本地预览上的真实浏览器渲染比较，截图及数据存入本目录。

对比数据.json 和 PNG 为当前实际算法输出。旧算法含随机顺序，其误差值随重新运行波动；新算法使用固定种子。历史 P6 区域规划截图保留在另一目录，不代表新算法结果。
