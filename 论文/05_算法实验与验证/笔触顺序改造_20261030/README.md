# 笔触顺序改造与离线工程核查

日期：2026年10月30日。范围为公开AI共创的笔触规划与播放，不改变旧版研究条件、问卷、评分及数据库。本记录不是参与者实验结果。

## 改造内容

1. 多尺度参考：保留原来的曲线笔迹及约2000次尝试上限，四阶段的尝试配额改为25%、45%、25%、5%；较早阶段没有可改进候选时，未使用的尝试可延续到后续阶段，因此配额比例不等于最终笔数比例。前三阶段依次使用较强、较弱和轻微的可分离滤波，最后使用清晰目标；各阶段重算方向场。白纸不因模糊参考而向外扩散颜色。上述数值为本次实现参数，不是绘画规律或已经验证的最佳值。
2. 邻域连续推进：以空间小格累计剩余误差，按误差与距离选择相邻工作区域；采样窗口向邻区重叠，笔触不按格子裁切。每次访问最多规划20次，连续3次没有正收益时可提前离开。候选评分综合画面改善、移笔距离、颜色和方向连续性；顺序在生成时确定，之后不重新排列已生成的覆盖层。
3. 素材续绘：已完成照片只更新素材范围及缓冲区域；原照片尚未完成时，优先响应素材并按当时尺度继续全图。较晚阶段介入可回到局部结构尺度，不重新清空画布。新加素材不作为贴图直接写入可见画布。
4. 抬笔运动：短距离更紧凑，远距离适度放慢，时长限定在20—320毫秒；笔身角度走较短的旋转路径，配合轻微抬起与透明度变化。抬笔阶段不落墨，真实笔迹仍由原弧长采样生成。暂停及速度变化保留笔内进度。

主要实现：`src/lib/expressive-painter.ts`、`src/lib/expressive-scheduling.ts`、`src/lib/stroke-playback.ts`、`src/components/creation/CoCreationStudio.tsx`及共创Worker。算法版本为`local-curved-painter-3-coherent`。没有新增模型、推理接口、网络服务或运行依赖。

## 离线对比方法

- 使用仓库内《日出·印象》、伦勃朗自画像和高更花卉静物三张既有素材，覆盖横幅景物、竖幅人物和细节较多的静物。它们不代表完整的用户照片分布。
- 原图按应用规则等比置入640×480白画布，规划最长边仍为320像素。旧、新算法均使用原色、概括60和相同2000次尝试上限，只绘制被接受的正收益笔触。
- 使用原生离线Canvas调用同一个`drawExpressiveStroke`绘制，比较各版本已接受笔数的25%、50%、75%、100%状态。进度图不是相同时长截图，也不严格等同于四个阶段边界。
- 平均空移距离按画布对角线800像素归一化；长空移暂定义为距离超过对角线四分之一。该阈值仅用于工程比较，不是已验证的感知分界。
- RGB RMSE比较终图与输入图的像素差异，不能评价艺术质量、个人表达或创造力。计算时长是本机Node离线运行的单次记录，不等于浏览器或手机性能结论。
- 完整照片追加花朵的离线检查还比较缓冲区以外的像素，防止局部续绘改写远处已完成画面。

具体计数、距离、误差与时长见同目录的`离线对比数据.json`和`素材续绘数据.json`。阶段对照图中Old为改造前，New为本次实现。

本次三图的平均空移距离分别下降75.4%、69.6%、72.9%；长空移比例由70.7%、57.8%、65.0%下降到4.0%、3.1%、3.8%。终图像素误差接近旧版，有升有降，不能据此宣称成画质量普遍提高。局部追加花朵的检查产生319笔，缓冲区之外改变的像素为0。当前版本是否更符合观看者对绘画过程的理解，仍待真实页面及用户评价。

图像文件：`顺序对比_impression_sunrise.png`、`顺序对比_self_portrait.png`、`顺序对比_flower_still_life.png`和`素材续绘对照.png`。另附带`.txt`后缀的旧规划器及核查脚本快照，供追溯离线计算方法；其中绝对路径属于本次机器环境，复用前需调整。

## 验证范围与限制

自动回归覆盖确定性、输入不可变、预算边界、阶段顺序、短距离连续推进、局部范围、中途介入继续全图、笔尖位置、转角、丝纹渐隐、光速完整播放及RAF卸载清理。TypeScript、ESLint及生产构建结果保留在同目录日志。

本地浏览器工具对`http://127.0.0.1:3001`报告保存的权限或管理策略拒绝访问，因此本次未通过浏览器点击上传、确认、暂停、保存或验收真实页面播放。未使用其他浏览器、原始CDP或间接方式绕过。离线成画与自动回归不能替代桌面、390px移动布局和真实设备的交互验收。

## 与论文的衔接

多尺度参考可联系Hertzmann的经典分层绘画方法；本文实现新增的是面向可观看过程的邻域调度、距离及方向连续性约束，以及素材介入时的状态衔接。原论文并未因此验证本项目的用户体验。

Hertzmann A. Painterly Rendering with Curved Brush Strokes of Multiple Sizes. SIGGRAPH 1998, 453–460. DOI: 10.1145/280814.280951. 原文：https://mrl.cs.nyu.edu/publications/painterly98/hertzmann-siggraph98.pdf

上述距离变化只能作为实现行为的工程证据；过程是否更容易理解、是否促进想法发展，仍需后续真实用户材料支持。
