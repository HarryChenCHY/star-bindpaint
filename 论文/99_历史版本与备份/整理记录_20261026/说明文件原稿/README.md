## 版本与存放规则

1. 继续编辑中期检查时使用`01_论文与报告/中期检查/`中2026年10月21日的评审意见修订版Word及配套PDF，后续改Word时应重新导出PDF。此前报告保持原样。
2. 当前已实现测试以`03_用户测试与研究方案/用户测试_v2_实验方法与实施说明.md`及当前程序协议为准；评审修订报告中的平行图、基线和分段引导属于后续方案，需预试及独立版本冻结后实施。旧规划和历史报告留作过程记录。
3. 算法输出、工程截图、合成测试数据分别留在对应子目录；它们不代表真人预试或正式实验结果。
4. 新增当前报告放`01`，模板放`02`，实验执行文档放`03`，设计说明放`04`，算法结果放`05`，工程验收放`06`，文献放`07`；替换下来的版本按日期放`99`。
5. 本次没有删除或合并同名文件。全部原始文件均有去向，重复版本、遗留Word临时文件也保留在历史目录。
